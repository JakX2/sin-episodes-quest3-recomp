# Phase 1681: original 67-byte locale-gated and 78-byte ASCII-fast name comparison

## Verified original PE32 evidence

Read-only disassembly of the unchanged owner-provided 2006 PE32 `client.dll` resolves the last abstract Phase1679 name comparator at `0x2425F81B` into a complete **67-byte CDECL function** (SHA256 `0905847aa7a5fa843447c965b7ed17f401401ad60bf6be835038df5637559806`, ending plain `RET` at `0x2425F85D`). The direct original name-finder callsite is `0x24197F16`, within SHA-pinned 121-byte original finder `0x24197ED0`.

The comparator checks a process-global DWORD at `0x243895D0` using an absolute memory operand with exactly **one** HIGHLOW relocation at `0x2425F81D`. When the flag is **zero**, execution takes an unconditional **tail JMP from `0x2425F824` to `0x24261C60`**, an additional complete 78-byte native ASCII-specialized case-insensitive comparison routine (SHA256 `9208efe7b20ebf707490aa3334dabf576a42bfabcb93356dfd2505c20dd6d658`, plain RET at `0x24261CAD`). When the global is nonzero, the 67-byte entry follows a distinct per-byte locale/ctype conversion loop. It calls still-separate original `0x2424C373` at two exact callsites `0x2425F838` and `0x2425F844`, passing one byte promoted to int each time. This mode returns the 32-bit subtraction of **converted second input minus converted first input**; the ASCII fast path returns the sign `{-1,0,+1}` of the comparison of the **first input against the second**, after folding ASCII `A..Z` to lowercase. The sign difference does not affect the only observed Phase1679 original caller, which requires merely zero for equality.

The original fast path has no HIGHLOW relocations, and neither function has claimed trailing INT3 padding because other functions begin immediately at their endpoints. Native source pointers and source locale globals are never dereferenced by public tests.

The full original `0x2424C373` locale character-conversion routine and its CRT locale tables are **not** translated here. A custom synthetic callback can demonstrate branch/call ordering but cannot certify exact accented-character behavior in the live retail game.
