# Phase 845: integrated portable VCD grammar

Composes Phase843 portable lexer, Phase837 root, Phase839 actor/channel, Phase840 event, Phase842 relative/absolute/flex tags, Phase836 loader and Phase841 named playback. New per-invocation adapter preserves hosted allocation, numeric, diagnostic and finalization contexts; old tokenizer, same-line and event/root dispatch callbacks can be null. Remaining root (scene_ramp/scalesettings) and event (event_ramp/flexanimations) block leaves explicitly receive the shared native cursor synchronously. Stable tokenizer_word remains host-provided and must not be mistaken for the adapter stack pointer. Parsed objects must not retain borrowed cursor/data. New ABI parse/load/scene; direct synthetic text test validates nested actor/channel/event, all four tag vectors, sorted timing, empty curve/scale blocks sharing cursor, and truncated grammar failure. Named load and playback compositions not yet positively tested through this adapter. No new original DLL addresses or full retail parsing claims. CI pending.
