# Phase 1017: composed entity-wide native overlay frame

Composes the original-derived capture/reset/restore (Phase1015), history pool (1014), sequence-change repair (1011), and clocked interpolation (1016). Entity vectors use original +7a4/+7b8, rows 0x20, watchers 0x44, count <=15. Repair uses original 240c19a0 immediate interpolation callback then event baseline at +7cc+4*i; the composition invokes actual native interpolation at that callback, followed by evaluation of every other active watcher once. This is a port-owned coordination API, not a claim of the engine's entire frame scheduling order. Metadata looping service remains explicit, as do clocks and preallocated per-watcher storage.

Preflight validates all active chains and row pointer identities, disjoint pool storage and encoded word ranges; rejects malformed second slot before mutating first. Result reports completed watcher operations, sample writes, repairs, raw copies and recycled nodes. A numerical/callback failure during execution can leave prior completed operations and repair changes; no transactional rollback promise. Callbacks must keep storage and actor stable. All external buffers must be valid, writable, nonoverlapping; no original global shared allocator or vtable installation. Windows loaded test covers two independent watchers, native correction/linear and Hermite output, event baseline, raw-copy gate, exact network restore, duplicate pool rejection, malformed later watcher preflight, reset and zero-count teardown.
