# Phase 807: response dispatch through integrated scene playback

Composes Phase 797 response selection/dispatch and Phase 806 integrated scene activation. The new versioned server-only export keeps existing ABI intact. Both generated sound and named VCD paths can use the native scene activation/registration route; the original raw audio, sentence and print branches are unchanged. Interruption and activation must share the same SceneManagerSession; the caller must bind both runtime views to the same manager. Retained sound storage remains host-owned. The loaded-pair regression dispatches a synthetic Speak response, checks duration and history callbacks, retained sound lifetime, native activation without the legacy callback, manager tick and removal. Null/mismatched lifecycle sessions are rejected before consuming the response. Selection/speak wrapper and named VCD paths are composed but not independently exercised by this new fixture. No new original function/address claims, retail NPC invocation, actual audio, VCD loading or engine vtable installation. No HL2-equivalent physics/models/rendering.
