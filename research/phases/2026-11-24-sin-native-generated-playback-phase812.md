# Phase 812: allocated native generated sound playback

Composes Phase810 generator and Phase811 constructors with original NPC sound wrapper and Phase806 activation/registration/simulation/cleanup. Optional new server-only ABI accepts raw storage allocation, parsed vector append and symbol initialization; no legacy create_parsed/create_child or lifecycle.generate callback required. Raw allocation failures preserve original three child attempts and null vector insertion; unlinked allocation release is a transport-failure adaptation. Native actor/channel/event/parsed constructors execute on dirty storage; event serial counter is module-wide host state. Connected regression creates a real reconstructed parsed scene with actual PE32 pointer words, binds actor/channel and event, uses recovered manager tick, dispatches and retires. Second fixture covers missing channel allocation with native construction of other children, no links and destruction. The host still supplies scene/entity factory, symbol/vector storage operations, original-compatible destructors, start (simulation bounds), audio effect callbacks and engine vtables. Tests synthetic, not retail playback. No new binary address claims or HL2-equivalent work.
