# Phase 981: map host shared scene admission

NativeNpcMapHost now accepts a complete borrowed ResponseSceneFilterBindings before opening its map-owned response registry. It injects the copied shared table together with the shared registry into actor-specific speech bindings, rejects competing shell filter contexts, prevents rebind/unbind while registry open, actors attached or observation active, and allows reuse across map unload/reopen. A persistent SceneCacheOwner adapted with SceneResponseServicesApi is compatible. Owner lifetime remains caller responsibility; host does not clear a borrowed cache. Existing external-registry and no-shared-filter routes unchanged. BSP fixture checks invalid binding, both actor routes, competing shell rejection, reentrant unbind guard, teardown and rebind. The map routing fixture probes filter callbacks, not actual audio. CI pending.
