# Phase 879: native nonuniform flex track spline

Direct original disassembly: 2210d890 synthesizes endpoints at time 0 and parent duration, neutral bank1 .5 or bank0 -min/(max-min) (0 if equal). Actual rows 12 bytes at track +14/+28, counts +20/+34. 2210d970 returns neutral without clamp when no rows, finds first closed interval [left,right] including synthetic endpoints, clamps neighboring sample indices to synthetic endpoints, computes t only for positive interval width, clamps t 0..1, calls 2226b720. That routine rescales the outer sample values to the center interval time width using the adjacent time gaps, except equal-time neighbors; then calls 2226b210 Catmull-Rom. Return clamped 0..1 for sampled spline. Input flags ignored by this original flex sample path, unlike generic ramp curve modes. New server API tests nonuniform interpolation (.6 expected from .2/.8 values with asymmetric time gaps), equality/duplicate timestamps, endpoints, neutral without clamp and overshoot. Phase 878 now optionally consumes raw track sample rows through existing storage callback instead of a hosted sample callback; intensity and controller-name lookup remain explicit. Raw data validation rejects nonfinite/unsorted/out-of-range samples and uses scalar double approximation rather than exact original x87 intermediate rounding. CI pending.
