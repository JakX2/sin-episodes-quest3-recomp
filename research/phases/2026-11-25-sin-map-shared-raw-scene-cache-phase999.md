# Phase 999: shared raw scene playback bindings at the map host

NativeNpcMapHost now accepts a complete borrowed NamedSceneCacheBindings table before opening the shared response registry. It copies the shell-specific generated response and named-playback tables for the synchronous observe call, inserts the shared raw cache only into an empty local cache table, preserves the owned VCD runtime pointer and rejects missing/competing routes without falling back. Lifetime restrictions mirror shared metadata admission: no rebind/unbind while registry open, NPCs attached or observe active.
