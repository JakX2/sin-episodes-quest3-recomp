# Phase 1382: Native Elite ammunition metadata defaults and edge cases

Reuse the already authenticated shared original_ammo_definitions API for optional index and max-carry defaults rather than duplicating the registration table. Live overrides remain independent and authoritative when present. Original 222aa770 second max-carry lookup treats -2 as unlimited and returns 999, while 222457d0 retains its first denominator. Preserve the original negative ratio. Original all-unordered or positive-infinite mapped candidates can reach 22266b00 with a null classname; the independent adapter intentionally skips this unsafe null factory call and exposes reward_missing_class. Regression covers native MAG/AR capacities, mixed native index/live maximum, unlimited, zero-over-zero, positive-over-zero, and CBasePlayer primary vtable. A separate local Clang++ C++17 harness copied the phase 1380 ratio compare/store functions and passed 1,000,196 signed integer pairs against x86 80-bit long double, six comparison bounds per pair (NaN bounds skipped), with ASan/UBSan. This is arithmetic-only evidence, not a DLL test. Windows CI pending.
